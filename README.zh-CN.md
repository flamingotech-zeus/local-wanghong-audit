# 本地网红店铺盘点与指数排行榜

[English](README.md) | [简体中文](README.zh-CN.md)

> 盘点某城市或区域的网红店铺清单，产出「网红指数排行榜」三件套：Excel 台账 + Word 报告 + 可交互 HTML 榜。

## 这是什么

这不是从一个搜索结果里扒出来的店名清单。那种清单来得便宜、也靠不住，一旦有人问一句"还开着吗"，整个东西就塌了。

它产出的是一份可追溯的排行榜：每一个分数都能点回到一条来源链接。确认不了的事实就标"待确认"，不编。

## 为什么开源

做本地项目的时候用过几次，每次都有用 —— 开一个品类、选一个点位、估一个市场。每次都要把同一套流程重搭一遍，后来就不重搭了。

它是一套调研方法，不是什么公司资产：数据源是公开的，评分模型是一组写明的权重，产出格式是通用的。里面没有属于我们的东西。

## 能做什么

- **四路并行调研。** 不同类型的来源分别查、再对齐，而不是一个搜索代表了全部。
- **五维加权指数。** 评分模型是写明的，每一分都对得上证据，不靠感觉给。
- **增量扩容。** 挂一个 `data2.py` 加上规则化自动评分，就能在一批的基础上扩第二批，不用从头再来。
- **两条工商数据落地路径。** 用来确认一家店在法律上是否还存在，而不是相信一条可能好几年前的平台信息。
- **一个脚本三种产物。** Excel 台账、Word 报告、HTML 榜从同一次运行出来，数字不会在几个格式之间飘。
- **一条兜底核验路径。** 浏览器自动化不可用的时候，用一个极简的 Node DOM 检查把核验这一步保住。

## 怎么用

说清楚区域和你要什么：

- "盘点一下某某区域的网红店"
- "给我一个排行榜，标出哪些已经倒了"
- "连锁的和非连锁的分开列"

开工前它会先问清四个口径，因为"网红"这个词在不同口径下指的不是一回事。

## 注意与边界

1. **"确认不了"是一个有效答案。** 这套方法宁可把某个事实标成未知，也不把它填得像真的。会有那么几格就是这么写的。
2. **指数是相对的，不是绝对的。** 80 分的意思是"在这一批里算高"，不是"百分制考了 80"。
3. **平台信息会过期。** 营业时间、是否闭店、甚至是否还存在，都可能过时好几年。这就是要有第二条工商数据路径的原因。
4. **口径问题不是可选的。** 跳过它们，产出的排行榜回答的是另一个问题。
